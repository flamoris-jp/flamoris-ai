## 4. 現在のユーザー機能

以下はソースの機能です。実機がそのrevision・schema・設定を備えたという意味ではありません。

| 呼出し元／操作 | ソース上の可否 | 条件・限界 |
| --- | --- | --- |
| Studio画像生成 | 可 | builtin txt2img／ordered LoRAの2テンプレート、ComfyUIとmodel catalogが必要 |
| StudioのComfyWorkFlow選択 | 基本テンプレートのみ | arbitrary graph／custom登録／版管理／v3合成は廃止 |
| Studio Agent AssistantをOpenAI APIで使用 | 可 | opt-in settings、許可されたtarget／model、Operatorの鍵・費用上限、全contextの送信同意。モデル変更は新しい会話 |
| Studio画像参照生成 | 不可 | 保存・upload・preview・履歴復元は保持。画像生成に参照が付いていると、明示的に外すまで拒否 |
| Studio LLM切替 | 条件付き可 | Rawは許可されたlocal aliasを選択。Agentはgrantされたlocal/OpenAI modelを新しい会話で選択。GPU自動切替なし |
| Studio Raw Intelligence | 可 | direct shared llama.cpp adapterのtext/reasoning/code。Raw editorにremote OpenAI選択はない |
| Studio音声生成 | 条件付き可 | opt-in Irodori CLI adapter、設定済みresource、Japanese／参照なし／最大30秒。既存HTTP serverだけでは契約を満たさない |
| Studio音楽生成／採譜 | 条件付き可 | opt-in YuE2／SheetSage2のnative契約・resource、WAV/ABCまたはMIDI/annotation。editor／routeの追加実装は不要 |
| ChatGPT Generation MCP | retained生成可 | matched外部catalog・認証・provider。画像／native Speech・Music・transcription以外を実装済みとはしない |
| ChatGPT ComfyWorkFlow登録 | 不可 | register／verify／全v3 toolsはsource/catalogから廃止 |
| ChatGPT Intelligence MCP | 外部facadeあり | Hub/plugin登録・稼働設定・fresh tool discoveryが必要。コードの存在だけでこの会話から呼べるとは判定しない |

Generationのactive job予約はprovider全体で1つです。複数ユーザーの所有権分離と、同時GPU inference／自動runtime handoffは別です。動画・decomposition・reference拡張・Controller・Agentの追加memory/toolsを今回の修正で実装したとはしていません。

## 5. 削除しなかったもの

- `WorkflowStore`／`workflow_id`／`workflows.list/build/save`は現役のgeneric recipe契約です。ComfyUI以外のnative providerも利用します。
- Runtimeの`WorkflowMachine`／serialized inputの互換名と`ExecutionPlan`は現役です。Generationの旧機構とは異なります。
- 保存済みschema-2/3を拒否するreader、旧active journalのunknown／busy fence、過去のprovider copyのidentity／retention guardsはデータ保護です。旧機能の再実行入口ではありません。
- 保存済みasset/input、会話、grant、historical evidence、Git/Issueの完了記録は保持しました。旧手順の固定リンクも過去の証拠であり、新しい実装指示ではありません。

`Workflow`という文字列がゼロになったことを完了基準にしていません。旧機構の実行・登録・合成・内部MCP経路が復活していないことと、現役契約・不確定処理・ユーザーデータが保護されることを基準にしました。
